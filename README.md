# Facebook Clone Website

A frontend clone of the core Facebook desktop interface, built as a practical hands-on project to practice modern web development, UI design patterns, and Git/GitHub version control workflows.

---

## 📌 Project Overview

This project is a recreation of Facebook's signature web layout. Developed during a Git and GitHub tutorial, the primary focus was to translate complex social media UI components into clean, semantic markup and maintain structured version history using Git branching, SSH authentication, and remote repository syncing.

---

## ✨ Features

- **Navigation Bar:** Global header featuring the brand logo, search input field, primary navigation tabs, and profile action icons.
- **Left Sidebar:** Quick access links to user profile, friends, groups, feeds, and shortcuts.
- **Main Feed:**
  - Story tray with card layouts.
  - "Create Post" interactive box (status updater, media upload buttons, feelings/activity tags).
  - Dynamic-style post feeds containing profile headers, post captions, image containers, and interactive reaction/comment bars.
- **Right Sidebar:** Contact lists, active status indicators, and community/sponsor panels.
- **Responsive Design:** Flexbox and CSS Grid layout structures designed to align components fluidly across various viewport sizes.

---

## 🛠️ Built With

- **HTML5:** Semantic structuring (`<header>`, `<nav>`, `<aside>`, `<main>`, `<section>`).
- **CSS3:** Custom styling, Flexbox, CSS Grid, media queries, and FontAwesome/Google icons.
- **JavaScript (Optional/Vanilla):** Basic DOM manipulation for interactive UI components (dropdowns, like toggles).
- **Git & GitHub:** Version control, SSH key configuration, local-to-remote tracking, and collaborative workflow practice.
